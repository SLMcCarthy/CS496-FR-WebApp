Future Iteration Planning V1 (5/20/22)

The following document outlines features, technologies, and fixes which we plan to implement in future iterations
A proper iteration plan will be developed following client feedback

-=-=-= Features =-=-=-

  1. Manual opening and closing of listings
    - From the listings panel, admins can toggle listings between open and closed
    - Users will be unable to see closed listings, admins will see closed listings darkened and marked as closed
    
  2. Auto opening and closing of listings
    - Auto open/close date form is implemented
    - When loading listings, backend must check to see if either date has arrived and set the listing to be opened / closed
